PRISM stream checker

If you found PRISM-StreamChecker in your server's logs, this page explains who it is and how to make it stop.

What it is

PRISM is a free web page for watching public live and on-demand video streams (HLS and DASH). Its list is built from public playlists, so a stream of yours may be in it. The stream checker is a small program on PRISM's server that checks the listed streams still play, so people who open PRISM are not shown dead ones.

What it does

For each stream, about once a day (more often for a few days after a stream fails, so a short outage does not hide it), it makes a few plain GET requests, the same ones a viewer's browser makes to start playback:

  • the stream's playlist (.m3u8, or the manifest for DASH);
  • the first rendition's playlist, when the first one is a list of renditions;
  • the first few kilobytes of one video segment.

Each request carries an Origin header naming https://prism.nooroticx.tv, so the checker sees whether your server lets PRISM's page play the stream (the CORS answer). It sends at most one request a second to the host named in a stream's address (a redirect can add a request, and a playlist that points at a shared video host can add requests to that host too). It reads no more than 256 KB of a playlist and 64 KB of a segment, follows at most three redirects, never signs in, and never fetches addresses on private or internal networks.

Its user agent is PRISM-StreamChecker/1.0 (+https://prism.nooroticx.tv/stream-checker/).

What it keeps

The checker stores only pass or fail for each stream: a short result word and the time of the check, plus whether the stream is live and which formats it offers. It does not keep the playlist, the video or anything else it read.

Asking for a stream to be removed

If you would rather PRISM did not list or check a stream, or any of the streams on your host, open an issue on PRISM's repository with the stream's address (or your host's name), and it will be removed from the list so the checker does not visit it again:

https://github.com/NooRotic/prism/issues/new

A host that answers with an error, or refuses PRISM's origin, is left out of PRISM's list; nothing needs to be done for that.
